## English (United States)

### App title

AquaHunter

### Short description

Official seafood market benchmarks with sources, history and offline maps.

### Full description

AquaHunter is a source-transparent seafood intelligence workspace for professionals.

The first release connects directly to Statistics Norway Statbank table 03024 and presents the latest published weekly export unit value and export weight for fresh or chilled farmed salmon. AquaHunter preserves the official NOK/kg unit, weekly period code and national export-benchmark meaning.

Key features:

- Latest official Norway farmed salmon export benchmark
- Weekly price history with 6-week, 30-week and 1-year views
- Published export-weight observations
- Source link, dataset ID, attribution, license and data cadence
- Offline world reference maps with no location permission or paid map request
- Four focused workspaces: Pulse, Markets, Radar and Network
- First-use maritime operations and legal risk acknowledgement
- Settings for background, language, risk notice and support email

AquaHunter does not manufacture missing observations. Buyer, trade, port, vessel, city-price and fish-probability records remain unavailable until exact production sources pass commercial-use, provenance and refresh review. Radar and Network retain the offline reference map while clearly stating when no approved operational layer is available.

The market value shown is a national weekly export unit value. It is not a city spot price, auction quote, investment recommendation or executable offer.

The bundled Natural Earth map is a geographic reference only. It is not a nautical chart and must not be used for navigation, legal-boundary decisions, fishing-zone determinations or safety decisions.

Fish Probability, when introduced, will describe statistical environmental suitability rather than sonar detection. It will not guarantee fish presence, catch, lawful access or voyage safety. Always follow official navigation information, maritime warnings, permits, closures, protected-area rules and the directions of competent authorities.

Data attribution: Source: Statistics Norway, table 03024. Licensed under CC BY 4.0.
